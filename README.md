# Echo

La veille sur Mac et iPhone : flux RSS, Atom et JSON Feed, newsletters et pages suivies, au même endroit.

**[Télécharger la dernière version](https://github.com/gambidrissi-dev/Echo-Share/releases/latest/download/Echo.zip)** · macOS 26 ou plus récent

Ce dépôt ne contient pas de code : il distribue Echo. L'app se met à jour toute seule
par [Sparkle](https://sparkle-project.org) depuis [`appcast.xml`](appcast.xml), et chaque archive est signée (EdDSA).

Toutes les apps, et **Vitrine** pour les installer d'un clic : https://apps-gambi.vercel.app/
